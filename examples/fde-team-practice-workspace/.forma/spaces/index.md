# Spaces

Customers, projects, evidence cards, patterns, roles, and portfolio observations are team-defined content conventions, not Forma core domains. Each stable record type is a separate configured content group with its own schema, create template, and partition guidance.

Use `guidelines/practice-partition-contracts.md` to route a new record and to preserve the human review boundary.
