# Forma

Forma is a lightweight, read-only workspace reader for Markdown-backed content. It keeps repository files and explicit schemas as the source of truth rather than becoming a CMS or a separate content store.

## Start here

- Read the [product direction](knowledge/product/product-direction.md) for the current product intent.
- Read the [Forma product definition](knowledge/product/choral-forma.md) for its principles, scope, and architecture.
- Open the configured Views and Browse sections to explore project records through their existing workspace projections.

## This workspace

The frontmatter in this root document configures the workspace. This Markdown body is its public, read-only introduction and is rendered at the root route by both the local WebApp and static site export.
